Чек-лист разработки. Задачи разбиты так, чтобы каждую можно было проверить независимо.

### Фаза 1: Фундамент и Парсер (Без UI)

- [ ] **T-1.1:** Создать структуру проекта и настроить локальную БД (SQLite) с таблицами `decks` и `cards`.
- [ ] **T-1.2:** Написать чистую функцию `parseLine(String line) -> Card?` с регулярным выражением для поиска разделителей.
- [ ] **T-1.3:** Написать Unit-тесты для парсера на всех примерах из спеки:
  - [ ] `Производная — скорость изменения функции` (длинное тире)
  - [ ] `Время: 10:30` (двоеточие, проверка что 10:30 не режется повторно)
  - [ ] `E = mc²` (равно)
  - [ ] `кто-то пришёл` (дефис без пробелов -> null)
  - [ ] `Определение:` (пустая правая часть -> null)
  - [ ] `A - B = C` (дефис с пробелами левее равно -> режется по дефису)
- [ ] **T-1.4:** Написать функцию `pluralize(count)` для слов «карточка/карточки/карточек» и покрыть тестами (1, 2, 5, 11, 21).
